# 게시글 좋아요(반응) 기능

## 문제 정의
현재 게시글에 대한 독자의 반응 표현 수단이 없다. 댓글 없이는 관심을 표현할 방법이 없어
사용자 참여도가 낮고, 인기 콘텐츠를 파악하기 어렵다.

## 제안 솔루션
- 게시글 상세 페이지에 좋아요 버튼 추가 (로그인 사용자만 가능)
- 좋아요 수 실시간 표시, 본인 좋아요 여부에 따라 버튼 상태 변경 (토글)
- 낙관적 업데이트(Optimistic Update)로 즉각적인 피드백 제공
- 게시글 목록 카드에 좋아요 수 뱃지 표시
- DB: `PostLike` 테이블 (userId + postId 복합 유니크)

## 기대 효과
- 사용자 참여도 및 인터랙션 증가
- 댓글 부담 없이 관심 표현 가능 → 소극적 독자 참여 유도
- 좋아요 수 기반 인기 게시글 정렬 기반 마련

## 개발 난이도
🟡 보통

## 우선순위 점수
8점

## 구현 힌트
- Prisma 스키마: `PostLike` 모델 추가 (`userId`, `postId`, `@@unique([userId, postId])`)
- `POST /api/posts/[id]/like` (토글: 있으면 삭제, 없으면 생성)
- TanStack Query `useMutation` + `onMutate` 낙관적 업데이트
- 비로그인 클릭 시 `/login` 리다이렉트 또는 토스트 안내

## 디자인 요구사항 (design-agent 전달용)
- 관련 페이지/컴포넌트: `PostDetail.tsx`, `PostCard.tsx`
- 예상 UI 변경 범위:
  - PostDetail 하단에 하트 아이콘 + 좋아요 수 버튼 (좋아요 시 채워진 하트로 변경)
  - PostCard에 좋아요 수 뱃지 (조회수 옆에 배치)
  - 비로그인 시 클릭하면 "로그인이 필요합니다" 토스트 메시지
- 참고할 기존 컴포넌트: `Button.tsx`, `PostCard.tsx`, `PostDetail.tsx`
